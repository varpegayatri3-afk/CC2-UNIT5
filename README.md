## 1. Aim

To represent water distribution points and pipelines as a weighted graph using an adjacency matrix, and apply Prim's algorithm to construct a minimum-cost network and BFS to explore connected villages.

## 2. Objectives

1. To represent villages as vertices and water pipelines as weighted edges.
2. To accept multiple village names and pipeline details from the user.
3. To create an adjacency matrix automatically based on pipeline connections and costs.
4. To implement Prim's algorithm to find the minimum-cost pipeline network.
5. To implement BFS to explore connected villages.
6. To use a switch-case menu for different operations.
7. To calculate and display the total minimum pipeline cost.

## 3. Problem Statement

To develop a C++-based Village Water Distribution System that represents multiple villages and their connecting water pipelines using a weighted graph. The system should allow users to enter village names and pipeline details, automatically generate an adjacency matrix, and use Prim's algorithm to find the minimum-cost network. BFS is used to explore connected villages and display the distribution network efficiently.
